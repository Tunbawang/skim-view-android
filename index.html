About

Skim View splits pasted English text into two columns, line by line: Keyword and Skimmed Word. This split doesn't come from the classic content-word / function-word distinction, or from part-of-speech theory — it comes from a simpler, independent observation: when skimming a sentence, a reader's eyes mainly settle on certain words and glide past the rest. Keyword marks what a fast reader's eyes tend to settle on; Skimmed Word marks what gets glided past. It runs the same classification engine used in the browser extension and the HTML tool, ported here as a fully offline Android app.

Because everything runs entirely on the device, it works without an internet connection, and the text you paste is never sent anywhere.

Installation

Because this app isn't distributed through Google Play, Android shows its standard unknown-source confirmation during installation.

  1. Download the APK file — Tap "Download app-release.apk" above.
  2. Tap the download-complete notification — If no notification appears, open app-release.apk from your file manager's Downloads folder.
  3. An "Install unknown apps" screen appears — A warning such as "Installing apps from this source isn't allowed" appears, along with a "Settings" button.
  4. Allow this source for your browser — On the settings screen that opens, turn on "Allow from this source."
  5. Go back and install — Tap "Install" to install the app as usual.

How to Use

Beyond opening Skim View directly and pasting text, you can select English text in any other app and call Skim View directly from there for a two-column split.

  1. Select the text you want to read — Press and hold, then drag to select a range of text.
  2. Tap "⋮" on the selection toolbar
  3. Scroll down through the list — App order varies by device.
  4. Tap "Skim View" — The selected text is passed directly to Skim View, and the split happens automatically.

FAQ

Why isn't this distributed through Google Play?

This is an individually maintained reading tool, distributed directly through GitHub together with its source code, so its behavior and classification logic are public and can be reviewed before installing.

Is the "unknown app" warning safe?

This is a standard Android OS mechanism shown for any app distributed outside Google Play. Decide based on whether you trust the source (this page and repository).

Can I turn this permission back off after installing?

Yes, any time from the Settings app, under Apps or Security.

このアプリについて

Skim Viewは、貼り付けた英文を1行ごとに「Keyword（要点語）」と「Skimmed Word（所流語）」の二列に自動で振り分けて表示する読解支援ツールです。ブラウザ拡張版・HTML版と同一の分類エンジンを、通信不要のオフラインAndroidアプリとして移植しています。

端末内で完結して動作するため、インターネット接続がない場所でも利用でき、入力した英文が外部に送信されることもありません。
