About

Skim View splits pasted English text into two columns, line by line: Keyword (content words) and Skimmed Word (function words, and words too ambiguous for a program to classify reliably). It runs the same classification engine used in the browser extension and the HTML tool, ported here as a fully offline Android app.

Because everything runs entirely on the device, it works without an internet connection, and the text you paste is never sent anywhere.

Installation

Because this app isn't distributed through Google Play, Android shows its standard unknown-source confirmation during installation. Follow the steps below (exact wording may vary by device and browser version).

  1. Download the APK file Tap "Download app-release.apk" above.
  2. Tap the download-complete notification If no notification appears, open app-release.apk from your file manager's Downloads folder.
  3. An "Install unknown apps" screen appears A warning such as "Installing apps from this source isn't allowed" appears, along with a "Settings" button.
  4. Allow this source for your browser On the settings screen that opens, turn on "Allow from this source."
  5. Go back and install Tap "Install" to install the app as usual.

FAQ

Why isn't this distributed through Google Play?

This is an individually maintained reading tool, built on the idea that splitting text into Keyword and Skimmed Word columns makes skimming easier for anyone reading English — native speakers and language learners alike. It's currently distributed directly through GitHub together with its source code, so its behavior and classification logic are public and can be reviewed before installing.

Is the "unknown app" warning safe?

This is a standard Android OS mechanism shown for any app distributed outside Google Play. The warning itself says nothing about the app's safety — decide based on whether you trust the source (this page and repository).

Can I turn this permission back off after installing?

Yes. You can turn off "install unknown apps" for any browser at any time from the Settings app, under Apps or Security.

よくある質問

なぜGoogle Playで配布していないのですか

個人が公開している読解支援ツールのため、まずはGitHub上でソースコードとともに直接配布しています。Keyword（要点語）とSkimmed Word（所流語）の二列に分けて表示することで、ネイティヴスピーカーであれ外国語学習者であれ、英語を読む人にとって流し読みがしやすくなるという考えに基づいています。動作や分類ロジックはコードとして公開されており、内容を確認したうえでインストールいただけます。

「提供元不明のアプリ」の警告は安全ですか

この警告は、Google Play以外の経路で配布されるすべてのAndroidアプリに共通して表示されるOS標準の仕組みです。警告自体はアプリの安全性を示すものではないため、配布元（本ページ・本リポジトリ）を信頼できるかどうかで判断してください。

インストール後、この許可設定は元に戻せますか

はい。設定アプリの「アプリ」または「セキュリティ」内から、ブラウザごとの「不明なアプリのインストール」許可はいつでもオフに戻せます。
